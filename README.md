## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Every change has been done on the main branch.

If you would want to apply changes PLEASE make a pull-request first (new branch)
